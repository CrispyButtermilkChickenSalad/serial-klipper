Open Fluidd or Mainsail on a Klipper host that is reachable only through a serial link. Everything runs in your browser: it talks to the serial-klipper host daemon over Web Serial. Nothing is uploaded.

Web Serial is not available. Use Chrome or Edge on desktop (https or localhost).

The host needs serial-klipper-host running on the port you pick. Close any other program using the port first.
